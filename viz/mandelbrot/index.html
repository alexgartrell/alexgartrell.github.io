How it works

Each pixel is a complex number c. Start at z = 0 and repeat z → z² + c. If |z| ever exceeds 2 it is certain to fly off to infinity, so c is outside the set; if it stays bounded, c is inside (black). The colours show how many steps the escape took. Counting steps gives hard bands, so the colour uses the fractional count n − log₂(log|zₙ| ÷ log B), which slides smoothly from one band to the next.

Fix c and instead let the starting point z vary, and you get that c's Julia set, shown in the corner for the point under your cursor. The Mandelbrot set is a map of all of them: when c is inside it, the Julia set is one connected piece; outside, it shatters into dust. Zooming deeper needs more steps before points escape, so the iteration budget grows with zoom until 64-bit floating point runs out of digits at about 1012×.

How it works

Every algorithm keeps a frontier of cells it has discovered but not yet explored, and repeatedly takes one out and adds its neighbors. They differ only in which cell they take next. BFS takes the oldest, so it spreads in rings and finds the path with the fewest steps, but it ignores mud. Dijkstra takes the cell that is cheapest to reach, so it finds the lowest-cost path even through mud.

A* takes the cell with the smallest cost so far + Manhattan distance to the goal. The distance never overestimates the remaining cost, so A* is still optimal, yet it leans toward the goal and explores far less. Greedy best-first uses the distance alone. It is often fastest, but it can be lured into dead ends and return a longer path.
